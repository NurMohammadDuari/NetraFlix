# Changelog

All notable changes to NetraFlix will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- **Quick-start guide** in README — how to run the web app in under a minute.
- **`BOUNDARIES.md`** — explicit documentation of what this project will not
  do (stream-extraction route, third-party code in the repo) and the
  legitimate alternatives.
- **GitHub topics** for discoverability (`netraflix`, `streaming`, `tmdb`,
  `anilist`, `pwa`, `self-hosted`, etc.).
- **`CHANGELOG.md`** (this file) and a feature request issue template.

### Added (earlier)
- **Original NetraFlix raster assets** — `clone/icon-192.png`,
  `clone/icon-512.png`, `clone/og-image.png`, generated by
  `tools/make-icons.mjs` (pure Node, no deps). Replaces the excluded
  original-site icons so manifest/SEO references resolve.
- **SEO** — full meta tags, Open Graph, Twitter cards, JSON-LD structured
  data, `robots.txt`, and `sitemap.xml`.
- **GitHub scaffolding** — `LICENSE`, `NOTICE`, `CONTRIBUTING.md`,
  `CODE_OF_CONDUCT.md`, `SECURITY.md`, CI workflow (syntax + JSON +
  third-party-code guard), issue/PR templates.

### Changed
- **README folder map and published/excluded lists** rewritten to match the
  real repository contents.
- **`NOTICE`** — the generated icons moved from "excluded" to "original".

## [0.1.0] — Initial release

### Added
- **REA inspection** of framextv.xyz with full evidence bundle (local-only).
- **Source recovery** — as-served bytes, beautified source, structural and
  heuristic recovery (local-only, excluded from the repo).
- **Working NetraFlix frontend clone** — runs from production bytes with 11
  idempotent patches (`clone/patch.mjs`): ad gate forced off, config
  override, trackers stripped. Verified playing video with 0 console errors.
- **Recreated metadata backend** (`server/`) — clean-room TMDB + AniList
  proxy, zero dependencies. `/api/stream` deliberately returns an
  explanatory error (see BOUNDARIES.md).
- **Analysis docs** — `analysis/api-map.md`, `analysis/routes.md`,
  `analysis/findings.md`.
- **Published repository** — original work only, third-party code excluded
  and guarded by CI.
